
# PrimeX Bot

A modular, multilingual Telegram bot built with Node.js.

## Features

- Modular command and event system
- Role-based permissions
- English and Bengali language support
- Telegram Business integration foundation
- PostgreSQL database support
- Render and Railway deployment
- HTTP health endpoint

## Requirements

- Node.js 24
- Telegram bot token
- PostgreSQL database (optional)

## Installation

```bash
npm install
npm start
```

Configure `config.json` before starting the bot.

## Deployment

Deploy using the included Dockerfile and the configuration files for Render or Railway.

## Health Check

```text
/health
```
